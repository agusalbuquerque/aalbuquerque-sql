## Módulo 5 - JOINs y UNION ALL

En este módulo se desarrollaron consultas para enriquecer la información
de ventas mediante la combinación de tablas relacionadas.

### Consultas desarrolladas

- Vista base de ventas con clientes, productos y categorías mediante INNER JOIN.
- Identificación de clientes sin compras mediante LEFT JOIN.
- Identificación de productos sin ventas mediante LEFT JOIN.
- Consolidación de ventas de diferentes períodos mediante UNION ALL.

El resultado de la primera consulta será utilizado como base para el
análisis posterior en Power BI.
